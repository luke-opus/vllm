2. 软件 BF16 转换
文档位置：docs/getting_started/installation/cpu.md:159-163
https://github.com/luke-opus/vllm/blob/6592612016059859dff1e93bd534edc1a5737615/docs/getting_started/installation/cpu.md#L159-L163

答案：RISC-V 软件 float32→bfloat16 转换采用最近值、平局取偶数（round-to-nearest-even）；NaN 保留为 canonical quiet NaN。CPU kernel 需要软件转换时自动选择，包括没有 native vector BF16 conversion 的情形；该舍入行为不需要额外 CLI 选项或环境变量。模型默认 dtype 不变。这不等于所有 CPU kernel 永远强制走软件转换，也不等于模型自动改为 BF16。
准确短引（L163）：
- “uses round-to-nearest-even and preserves NaNs as canonical quiet NaNs”
- “The model's default `dtype` is unchanged.”

3. OpenMP worker 预加载
文档位置：docs/getting_started/installation/cpu.md:257-259
https://github.com/luke-opus/vllm/blob/dfdc85947fe914d04906f5d0206c020c208bd400/docs/getting_started/installation/cpu.md#L257-L259

答案（文档明确限定 Linux，包括 RISC-V）：
- PyTorch bundled libgomp 可用时：vLLM 在启动 CPU workers 之前把它加入 LD_PRELOAD。
- LD_PRELOAD 已有 OpenMP runtime 时：保留已有 runtime。
- PyTorch 源码或发行版构建未捆绑 libgomp 时：使用其已经配置的 runtime。
准确短引（L259）：
- “PyTorch's bundled `libgomp`”
- “An existing OpenMP runtime in `LD_PRELOAD` is preserved”
- “use their configured runtime”
